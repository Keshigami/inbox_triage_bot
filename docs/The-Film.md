# The film

`demo/film.mp4` is 90 seconds in four chapters, made for engineers and project managers who have ninety seconds.

1. **What it does** (0 to 17 s): a terminal prompt runs the project's real first command and the response becomes a printed object. Offline mode: routed to CRM. Nothing sent. Then the stake: Six emails. One is a fifty-seat lead. Can it route without sending anything?
2. **How it is built** (17 to 40 s): a paper model of the pipeline, stage by stage, with the reveal: What the validators guarantee · tests/test_triage.py, the one line of code that matters, the API call and the tests.
3. **The proof** (40 to 68 s): the real app, recorded. Use sample, Triage, offline: Sales, route CRM Every log line says [SIMULATED] All six, offline: hand label beside each answer
4. **The answer** (68 to 90 s): 0, messages sent · every route line is [SIMULATED]. And it ships. One limit: Offline answers Sales every time: one of six. Then the prompt types `just setup && just up`.

`demo/film-60s.mp4` is the same without the proof chapter. `demo/demo.mp4` is the plain captioned walkthrough of the app.

Every number in the film comes from the project's own metrics, findings or a live response; nothing is drawn by hand. The film pipeline lives in the author's workspace, not in this repo.
